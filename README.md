# Sugam — Hackathon Submission Package

Sugam is an independent natural-language railway booking prototype by Shubham Kashyap Jena (NST–ADYPU).

## Included
- Working front-end prototype
- Netlify serverless function for OpenAI-powered intent parsing
- Research paper PDF
- Problem statement and product explanation
- Hackathon brief: what to build, strong-build checklist, what not to do, submission checklist, judging criteria, and next-stage process
- Explicit OpenAI API, model, service, data and research limitations

## Deployment
Upload the contents of this folder to Netlify. Configure `OPENAI_API_KEY` as a server-side Netlify environment variable if live parsing is desired. Never expose the key in client-side JavaScript.

## Safety
The prototype uses synthetic train, passenger, payment and PNR data. It does not access or interfere with live government or railway systems and is not an official IRCTC product.


## Official-status disclosure
SUGAM: Simplified Unified Guidance and Assistance for Mobility is an independent prototype for simplifying natural-language railway booking workflows. It is not an official IRCTC or government system and is not affiliated with IRCTC.
